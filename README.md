# 原神帳號切換器（Genshin Account Switch）

這是一個 Windows 桌面小工具，用於在《原神》登入畫面快速切換帳號與密碼。
工具會自動偵測原神視窗，並在需要時浮在視窗上方，協助你以 **Ctrl+V** 兩次貼上帳號與密碼。

> 作者：PICDarcy

## 功能特色

- 偵測原神視窗，啟動後自動跟隨視窗位置
- 一鍵複製帳號，並在放開 Ctrl+V 後自動切換為密碼
- 支援多組帳號管理（新增 / 編輯）
- 迷你化顯示（點擊 Logo 可展開）
- 登入完成後自動清空剪貼簿

## 安裝與使用

### 方法 1：直接執行（推薦）

1. 下載 `原神帳號切換器.exe`
2. 雙擊執行（首次執行可能需要系統管理員權限）

### 方法 2：使用原始碼

1. 安裝 Python 3.10+（建議）
2. 安裝依賴：

```bash
pip install pyperclip psutil pywin32
```

3. 執行程式：

```bash
python main.py
```

## 使用說明

1. 開啟原神登入畫面
2. 開啟本程式，選擇帳號
3. 程式會將帳號複製到剪貼簿，請在原神輸入框按 **Ctrl+V**
4. 放開 Ctrl+V 後，程式會切換剪貼簿為密碼，再按一次 **Ctrl+V**
5. 登入完成後剪貼簿會自動清空

## 注意事項

- `accounts.json` 內包含帳號密碼，請勿上傳或分享
- 程式需要系統管理員權限才能偵測原神視窗
- 若原神未開啟，程式會自動結束
